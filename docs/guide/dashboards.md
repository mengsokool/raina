# Dashboards: สร้างหน้าจอมอนิเตอร์และสั่งงาน

Dashboard ใน Raina คือพื้นที่แสดงสถานะการทำงานของอุปกรณ์แบบเรียลไทม์ และใช้เป็นแผงสั่งการส่งคำสั่งกลับไปยังฮาร์ดแวร์จริง คุณสามารถออกแบบหน้าจอได้อย่างอิสระโดยการลาก Widget มาวาง ปรับขนาด และจัดตำแหน่งลงบนกริดตามความเหมาะสมของการใช้งาน

## สร้างและออกแบบ Dashboard

ในการสร้างหน้าจอใหม่ ให้เข้าไปยังโปรเจกต์ที่ต้องการแล้วเลือกแท็บ **Dashboards** จากนั้นกดสร้าง Dashboard ใหม่ เมื่อเปิดเข้าสู่โหมดแก้ไข (Edit) คุณจะพบกับพื้นที่ทำงานหลัก 3 ส่วน ได้แก่ แถบเลือกวิดเจ็ต (Palette) ทางด้านหนึ่ง พื้นที่กริดสำหรับจัดวางเลย์เอาต์ตรงกลาง และแผงตั้งค่าคุณสมบัติ (Settings) ที่จะแสดงขึ้นมาเมื่อคุณคลิกเลือกวิดเจ็ตตัวใดตัวหนึ่ง

ขั้นตอนการสร้างหน้าจอก็ง่ายมาก เพียงลากวิดเจ็ตที่ต้องการมาวางลงบนกริด ปรับขนาดกว้างยาวให้พอดี จากนั้นในแผงตั้งค่า ให้เลือกผูกวิดเจ็ตนั้นเข้ากับตัวแปรที่คุณต้องการแสดงผล แล้วกดบันทึกการเปลี่ยนแปลง

เมื่อคุณสลับไปยังโหมดมุมมองปกติ (View) ข้อมูลจะเริ่มสตรีมเข้ามาทันที โดยในจังหวะแรกที่เปิดหน้าจอ ระบบจะดึงภาพรวมสถานะล่าสุดของทุกตัวแปรมาแสดงผลก่อน จากนั้นเมื่อมีข้อมูลใหม่ส่งเข้ามาจากอุปกรณ์ ตัวเลขและกราฟบนหน้าจอก็จะขยับอัปเดตแบบเรียลไทม์ทันที

> หากเปิดดู Dashboard บนสมาร์ตโฟนหรือแท็บเล็ต ระบบจะจัดเรียงวิดเจ็ตใหม่เป็นแถวแนวตั้งให้อ่านง่ายบนหน้าจอขนาดเล็กโดยอัตโนมัติ คุณจึงไม่ต้องเสียเวลาจัด Layout แยกสำหรับอุปกรณ์พกพา

## เลือก Widget ให้เหมาะกับงาน

Raina มี Widget มาตรฐานให้เลือกใช้งาน 8 ชนิด โดยแบ่งกลุ่มตามหน้าที่ออกเป็นกลุ่มแสดงผลและกลุ่มส่งคำสั่งควบคุม

| วิดเจ็ต | กลุ่ม | เหมาะสำหรับ |
| :--- | :--- | :--- |
| Value | Monitor | แสดงค่าล่าสุดเพียงค่าเดียว เช่น อุณหภูมิปัจจุบัน หรือสถานะเซ็นเซอร์ |
| Chart | Monitor | แสดงแนวโน้มข้อมูลย้อนหลัง โดยเลือกดูช่วงเวลาย้อนหลังได้ตั้งแต่ 30 วินาที ถึง 24 ชั่วโมง |
| Gauge | Monitor | แสดงข้อมูลที่มีขอบเขตชัดเจน เช่น ระดับแบตเตอรี่ หรือความแรงสัญญาณ พร้อมกำหนด Min/Max |
| Percentage | Monitor | แสดงข้อมูลในรูปแบบเปอร์เซ็นต์ เช่น ความจุถังน้ำ หรือความคืบหน้า พร้อมระบบเปลี่ยนสีตามเกณฑ์ |
| Toggle | Control | สวิตช์เปิด/ปิด เช่น สั่งเปิดรีเลย์ หรือควบคุมการทำงานของปั๊มน้ำ |
| Push | Control | ปุ่มกดติดปล่อยดับ (ส่งค่า `true` ขณะกด และส่ง `false` เมื่อปล่อยมือ) |
| Slider | Control | ปรับค่าตัวเลขแบบต่อเนื่อง เช่น ความสว่างหลอดไฟ รอบพัดลม หรือค่า Setpoint พร้อมกำหนด Min/Max/Step |
| Color | Control | วงล้อเลือกสีไฟ สามารถเลือกส่งค่าในรูปแบบ Hex, HSV หรือ RGB |

Widget ในกลุ่ม Control ทุกตัวจะผูกการทำงานเข้ากับชื่อตัวแปรหนึ่งชื่อเสมอ เมื่อมีผู้ใช้กดสวิตช์หรือเลื่อนปรับค่าบนหน้าจอ Raina จะส่งค่านั้นตรงไปยังอุปกรณ์ทันที โดยระบบจะตรวจสอบสิทธิ์ของผู้ใช้งานในขณะนั้นด้วยว่าจะต้องได้รับสิทธิ์ `canControl` ในหน้านี้จึงจะสามารถส่งคำสั่งได้ ซึ่งคุณสามารถอ่านรายละเอียดการจัดการสิทธิ์ได้ใน [Projects และสิทธิ์ผู้ใช้](./projects-and-access.md)

## การแชร์ Dashboard

เมื่อต้องการเปิดให้ทีมงานหรือลูกค้าเข้าดู Dashboard คุณสามารถกดปุ่ม **Share** หรือ **Share & Permissions** ที่มุมบนของหน้าจอ ซึ่งมีโหมดการเข้าถึงให้เลือก 3 รูปแบบ

| โหมด | ลักษณะการทำงาน |
| :--- | :--- |
| Public access | ใครก็ตามที่มีลิงก์ `/public/d/<token>` สามารถเปิดดูได้ทันทีโดยไม่ต้องเข้าสู่ระบบ |
| Restricted access | ต้องล็อกอินด้วยบัญชีผู้ใช้ที่มีสิทธิ์เข้าถึง Dashboard หน้านี้เท่านั้น |
| Paused | ระงับการเข้าถึงผ่านลิงก์ชั่วคราว ลิงก์เดิมยังคงอยู่และเปิดใช้งานใหม่ได้ทุกเมื่อ |

สำหรับงานส่งมอบลูกค้า หากลูกค้าต้องการเพียงแค่เปิดจอมอนิเตอร์ดูภาพรวมอย่างเดียวโดยไม่ต้องการสั่งงาน การเปิดใช้งาน Public access แล้วส่งลิงก์ให้เปิดดูจะเป็นวิธีที่สะดวกที่สุด แต่ถ้าเป็นกรณีที่มีลูกค้าหลายกลุ่ม หรือต้องการจำกัดไม่ให้ทุกคนกดปุ่มสั่งงานอุปกรณ์ได้ แนะนำให้สร้างบัญชี Client แล้วกำหนดสิทธิ์ราย Dashboard จะมีความปลอดภัยและรัดกุมกว่า ส่วนงานติดตั้งชั่วคราวหรืองานสาธิต เมื่อจบงานแล้วคุณสามารถสลับโหมดเป็น Paused เพื่อปิดการเข้าถึงชั่วคราวแทนการลบหน้าจอทิ้งได้

## พฤติกรรมการทำงานแบบ Realtime

เบื้องหลังการทำงานแบบเรียลไทม์ เบราว์เซอร์ของคุณจะเปิดการเชื่อมต่อผ่าน WebSocket เพื่อรอรับข้อมูลที่ส่งเข้ามา ทำให้หน้าจออัปเดตสถานะได้เองโดยที่คุณไม่ต้องคอยกดรีเฟรชหน้าเว็บ หากเครือข่ายของคุณมีการบล็อก WebSocket ระบบจะสลับไปใช้ Server-Sent Events (SSE) เป็นโหมดสำรองให้ทันทีโดยอัตโนมัติ ซึ่งในโหมดนี้ คำสั่งควบคุมจาก Widget จะถูกส่งผ่าน HTTP แทน แต่ผลลัพธ์ในการสั่งงานอุปกรณ์จะเหมือนกันทุกประการ

นอกจากนี้ เพื่อไม่ให้สิ้นเปลืองทรัพยากรของเครื่องลูกข่าย หน้า Dashboard แต่ละหน้าจะดึงและประมวลผลเฉพาะตัวแปรที่มี Widget ผูกไว้ในหน้านั้นเท่านั้น ตัวแปรอื่น ๆ ภายในโปรเจกต์เดียวกันที่ไม่ได้ถูกนำมาจัดวางบนจอ จะไม่ถูกสตรีมมารบกวนหน้าจอนี้

เมื่อมีหน้าจอมอนิเตอร์พร้อมแล้ว คุณสามารถต่อยอดการทำงานด้วยการตั้งเงื่อนไขสั่งงานอัตโนมัติได้ใน [Automations](./automations.md)
